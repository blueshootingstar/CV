h, w = img.shape[:2]

\item \textbf{实验小结}

在任务1中，我对图像进行了五种几何变换操作。平移操作通过构造仿射变换矩阵，使用 warpAffine 实现图像在x和y方向上的偏移。缩放操作分别使用了指定目标尺寸和按比例缩放两种方式。翻转操作通过 flip 函数的不同参数实现了水平、垂直和水平+垂直三种翻转效果。旋转操作通过 getRotationMatrix2D 计算旋转矩阵，以图像中心为旋转中心进行旋转。缩略操作则是将缩小后的图像通过数组切片直接覆盖到原图的左上角区域。

# 转换为灰度图
gray = cv2.cvtColor(img2, cv2.COLOR_BGR2GRAY)

# 调整为正方形（边长不小于500像素）
gh, gw = gray.shape[:2]
side = max(gh, gw, 500)
gray_square = cv2.resize(gray, (side, side))

# 创建圆形掩膜
mask = np.zeros((side, side), dtype=np.uint8)
center2 = (side // 2, side // 2)
radius = side // 2
cv2.circle(mask, center2, radius, 255, -1)

# 位运算实现圆形切片
result = cv2.bitwise_and(gray_square, gray_square, mask=mask)
\end{lstlisting}
